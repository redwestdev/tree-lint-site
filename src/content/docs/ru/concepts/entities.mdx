---

**Сущность** — именованный тип узлов проекта, который Tree-lint распознаёт по `matches` и проверяет правилами `rules`. Сущности объявляются в секции `entities` конфига:

```ts
entities: {
  component: {
    matches: {
      type: 'directory',
      name: '[A-Z]*',
      children: [
        { type: 'file', name: '*.tsx' },
        { type: 'file', name: 'index.ts' },
      ],
    },
    rules: {
      nameLength: { type: 'error', max: 20 },
    },
  },
},
```

Сущность описывает соглашение о конкретном виде файлов или папок: «компонент — это папка с `*.tsx` и `index.ts`», «хук — это файл с именем `use*`». Одна сущность отвечает на два вопроса:

- **как распознать узел** — поле `matches`: тип узла, шаблон имени и обязательный состав папки;
- **что проверить** — поле `rules`: правила, которые применяются к каждому распознанному узлу.

Распознавание всегда идёт раньше проверки: если узел не совпал с `matches`, правила `rules` этой сущности к нему не применяются.
