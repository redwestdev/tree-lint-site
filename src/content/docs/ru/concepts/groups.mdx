**Группа** — способ применить правила к папке по паттерну имени, не объявляя её сущностью. Она применяется к «обычным» папкам, которые не стали слоями и не распознаны как сущности, и работает как `matches` + `rules` в одном объекте:

```ts
groups: {
  name: "[a-z]*",
  children: [{ type: "file", name: "*.test.ts" }],
  rules: { nameLength: { type: "warning", max: 20 } },
},
```

В отличие от `layers` и `entities`, `groups` — это один объект, а не словарь: одна группа на весь конфиг.

Группа отвечает на два вопроса:

- **какие папки под неё попадают** — необязательный `name` (глоб имени) и необязательный `children` (состав папки);
- **что проверить** — `rules`, которые применяются к самой папке.

Группа нужна, когда важно проверить папки по имени или составу, но объявлять их сущностями со слоями не хочется — например, каталоги тестов.
