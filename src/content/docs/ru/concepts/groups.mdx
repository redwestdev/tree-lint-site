**Группа** — способ применить правила к папке по паттерну имени, не объявляя её сущностью. Она применяется к «обычным» папкам, которые не стали слоями и не распознаны как сущности, и работает как `matches` + `rules` в одном объекте:
Группа создавалась как способ разделения сущностей внутри слоя на группы путем помещения их в папку.
Группа не может назвываться именем слоя. (показать пример со структур)

(показать пример с архитектурой где слой поделен на группы причем группы в группах)
Группа не может находится внутри сущности (на первом уровне вложености).
Это может быть частью сущности при указании такого в конфиге.

(нужен пример со структурой где папка внутри сущности)

Группу можно определить и по имени файла (к примеру наличие на первом уровне index.ts и остальных групп может обозначает что это группа)

```ts
groups: {
  name: "[a-z]*",
  children: [{ type: "file", name: "*.test.ts" }],
  rules: { nameLength: { type: "warning", max: 20 } },
},
```

Технически вы можете поставить в группу что угодно но мы рекомендуем использовать группу для сегментации сущностей.

Группа -> Слой -> Группа -- не супер
Слой-> Группа -> Сущность -> Слои -> Cущность
Слой-> Группа -> Группа -> Сущность

Группа нужна, когда важно проверить папки по имени или составу, но объявлять их сущностями со слоями не хочется — например, каталоги тестов.
