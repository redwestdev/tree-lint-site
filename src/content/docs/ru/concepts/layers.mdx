title: Слои
description: 'Слой — папка с точным именем, внутри которой распознаются сущности.'
---

**Слой** — папка, имя которой **точно** совпадает с ключом секции `layers` (глобы здесь не поддерживаются). Слои распознаются на любой глубине внутри `roots`:

```ts
layers: {
  components: {
    entities: ["component"], // сущности, которые распознаются внутри слоя
    rules: { isEmpty: { type: "warning" } }, // необязательные правила для самого слоя
  },
},
```

## Как слои связывают сущности и папки

Сущности ищутся **только внутри слоёв** (или внутри другой сущности — см. [вложенные сущности](/ru/matching/entities/#вложенные-сущности)). Сущность, не перечисленная ни в одном слое, не будет распознана нигде. Если сослаться на необъявленную сущность, конфиг будет отклонён с ошибкой.

Слой ограничивает зону действия сущности: например, `hooks: { entities: ["hook"] }` означает, что хуки распознаются только внутри папок с именем `hooks` внутри `roots`.

## Правила для самого слоя

Слой — это обычная папка, поэтому для него можно задать собственные `rules` — они применяются к самой папке-слою.
