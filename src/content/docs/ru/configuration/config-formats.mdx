Tree-lint поддерживает несколько форматов файла конфигурации. Рекомендуемый формат — TypeScript: он даёт типизацию через `createConfig` и позволяет описывать собственные проверки в `custom()`.

## Поддерживаемые форматы

- `tree-lint.config.ts` (рекомендуется)
- `tree-lint.config.js`
- `tree-lint.config.mjs` / `tree-lint.config.mts`
- `tree-lint.config.json`
- `tree-lint.config.yaml` / `tree-lint.config.yml`

При использовании конфигураций в формате `json` или `yaml` функциональность будет ограничена (нет поддержки кастомных правил через callback).

При сканировании Tree-lint ищет файл конфигурации, начиная с текущего каталога и поднимаясь вверх по дереву, поэтому команду можно запускать из любой подпапки проекта.

## Ограничения декларативных форматов

В `json` и `yaml` доступны только предопределённые правила (`name`, `nameLength`, `size`, `lineCount`, `childrenAmount`, `isEmpty`) — функцию обратного вызова в них объявить нельзя. Правило `custom()` доступно только в конфигах `.ts` и `.js`. Подробнее — на странице [Свои правила](/ru/configuration/custom-rules/).

> Конфигурация выполняется как код (TypeScript). Используйте Tree-lint только с доверенными конфигурациями — подробнее на странице [Устранение проблем и безопасность](/ru/reference/troubleshooting/).
