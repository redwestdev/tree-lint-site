Tree-lint — это линтер для файловой структуры. Идея простая: вы фиксируете свои договоренности о структуре проекта в конфигурации, а инструмент автоматически следит за порядком. Проверки можно запускать как локально, так и в CI.

## Возможности

- распознавание сущностей по названиям и составу папок;
- проверка имен, наличия нужных файлов, длины названий, размера и количества элементов;
- собственные правила через `custom` с любым текстом ошибки;
- разделение на строгие (блокирующие) ошибки и простые предупреждения;
- ограничение области сканирования с помощью `roots` и `ignore`;
- интеграция с CI: если найдены нарушения, процесс завершается с кодом `1`, если всё по правилам — с кодом `0`.

## Ограничения

С чем инструмент не работает:
- **анализ кода и импортов** — проверяется только структура и названия;
- **автоматическое исправление** — инструмент указывает на нарушения, но изменения вносит разработчик;
- **символические ссылки (symlinks)** — при сканировании они игнорируются.

> Tree-lint не навязывает конкретную архитектуру. Он подойдет для слоистых и модульных структур, для легаси и проектов с кодогенерацией — для любых проектов, где есть правила организации файлов, которые можно описать.

## Как читать документацию
