Для работы Tree-lint требуется [Node.js](https://nodejs.org/) версии 18 или выше.

  <TabItem label='pnpm'>


  </TabItem>

Пакет устанавливается как dev-зависимость и добавляет команду `tree-lint`.

## Как запускать локально

Команда `tree-lint` лежит в `node_modules/.bin` и доступна, когда менеджер пакетов добавляет этот каталог в `PATH`. Это происходит:

- внутри скриптов `package.json` — npm, pnpm и yarn добавляют локальный `node_modules/.bin` в `PATH` для каждого скрипта;
- при запуске через `npx tree-lint`, `pnpm exec tree-lint` или `yarn tree-lint`.

Проще всего добавить скрипт:

```json
{
  "scripts": {
    "lint:tree": "tree-lint scan"
  }
}
```

и запускать его как `npm run lint:tree`, `pnpm lint:tree` или `yarn lint:tree`. Этот же скрипт позже пригодится в CI: проверка будет запускаться одной командой и локально, и в пайплайне.
