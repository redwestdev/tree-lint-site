## Безопасность

> Конфигурация выполняется как код (TypeScript).
>
> **Важно:** Используйте Tree-lint только с доверенными конфигурациями. Если вы берете конфиг из стороннего источника, убедитесь в его безопасности, так как он может содержать вредоносный код.

Исполняемые конфиги — это файлы `.ts` и `.js`. В декларативных форматах `.json` и `.yaml` пользовательских функций нет, и набор проверок ограничен предопределёнными правилами — подробнее на странице [Форматы конфигурации](/ru/configuration/config-formats/).

## Частые проблемы

- **"Configuration file not found"** — создайте конфиг командой `tree-lint init` или укажите существующий через `--config-path`.
- **Символические ссылки** — Tree-lint их не поддерживает и пропускает при сканировании.
- **Кастомные правила должны возвращать boolean** — любой другой результат callback в `custom()` считается нарушением.
- **В правиле `custom()` обязателен `type`** — без него Tree-lint 0.0.5 завершается внутренней ошибкой. См. [Свои правила](/ru/configuration/custom-rules/).
- **Правило `size` измеряется в килобайтах** — при этом `node.size` внутри `custom()` — в байтах. См. [Справочник встроенных правил](/ru/reference/built-in-rules/).
- **Папка, содержащая только пустые файлы, считается пустой** — правило `isEmpty` проверяет суммарный размер узла. См. [Справочник встроенных правил](/ru/reference/built-in-rules/).
