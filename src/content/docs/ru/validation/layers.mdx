Слой — это обычная папка, поэтому для него можно задать собственные `rules` в секции `layers.*.rules`. Правила применяются к самой папке-слою, а не к сущностям внутри неё: имя слоя, его размер, число детей и содержимое.

## Доступные правила

Для слоя действуют правила, применимые к папкам: `name`, `nameLength`, `size`, `childrenAmount`, `isEmpty` и `custom()`. Полный список и параметры — на странице [Валидация сущности](/ru/validation/entities/#встроенные-правила).

```ts
layers: {
  components: {
    entities: ["component"],
    rules: {
      isEmpty: { type: "warning" },
      nameLength: { type: "error", max: 20 },
    },
  },
},
```

## Пример: только разрешённые форматы файлов

Распознавание сущностей не запрещает «лишние» файлы в слое: `matches` игнорирует то, что не перечислено в `children`. Поэтому проверка «в папке лежат только файлы нужных форматов» делается правилом на самом слое — оно видит всех детей папки.

Возьмём папку документации: внутри должны лежать только файлы `.md` и `.mdx`, а `README.txt` — нарушение.

```ts
import { createConfig } from '@redwestdev/tree-lint';

export default createConfig({
  roots: ['content'],

  entities: {
    doc: { matches: { type: 'file', name: '*.{md,mdx}' } },
  },

  layers: {
    docs: {
      entities: ['doc'],
      rules: {
        custom: {
          type: 'error',
          message: 'В папке документации могут лежать только файлы .md и .mdx.',
          callback: (node) =>
            node.children.every(
              (child) => child.extension === 'md' || child.extension === 'mdx'
            ),
        },
      },
    },
  },
});
```

Здесь `node` — это `LayerNode`: доступны `children` и базовые поля. Подробнее о типах узлов — на странице [Валидация сущности](/ru/validation/entities/#поля-объекта-node).

Запуск для папки `content/docs` с `README.txt` внутри:

```
content/docs
  ✖ В папке документации могут лежать только файлы .md и .mdx.

Errors: 1, warnings: 0.
✖ Validation failed.
```

**Почему здесь нужен `custom`.** Сущность `doc` умеет распознавать только правильные файлы: `README.txt` под неё не подпадает, и без проверки на слое он остался бы незамеченным. Правило `custom` на слое видит всех детей папки — и подходящих, и лишних. Не забудьте `type: "error"` — без него Tree-lint 0.0.5 завершается внутренней ошибкой.
