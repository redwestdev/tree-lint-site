---
title: Доступні поля об'єкта node всередині custom()
description: "Поля об'єкта node, доступні всередині функції-колбека власної перевірки."
---

Функція-колбек отримує вузол, тип якого залежить від місця оголошення правила — див. таблицю на сторінці [Використання перевірки custom](/uk/rules/custom-usage/). Схеми полів нижче довідкові: блоки показують склад полів, а не готовий до виконання файл.

## 1. Базові поля (доступні в усіх вузлів)

```ts
{
  name: string;        // Ім'я файла або папки
  path: string;        // Повний шлях до вузла
  size: number;        // Розмір у байтах; для папок — сума всіх вкладених файлів
  ignored?: boolean;   // true, коли вузол збігся з ignore-патерном
  unreadable?: boolean;// true, коли вузол не вдалося прочитати
  hidden?: boolean;    // true, коли ім'я починається з "."
  isValid?: boolean;   // true за замовчуванням; false у вузлів із порушенням рівня error
  isExcluded?: boolean;// true, коли ignored або unreadable — такі вузли не беруть участі в перевірках
  rules?: object;      // Правила з конфіга, застосовані до цього вузла
  validate?: () => []; // Службовий метод рушія; не викликайте його всередині custom
}
```

Виключені вузли (`isExcluded: true`) до правил не доходять: якщо вузол потрапив у функцію `custom`, він не виключений.

## 2. Додаткові поля файла (`FileNode`, `FileEntity`)

```ts
{
  ...БазовіПоля,
  extension: string;   // Розширення файла без крапки, наприклад "ts"
  lines: number;       // Кількість рядків у файлі
}
```

## 3. Додаткові поля папки (`DirNode`, `LayerNode`, `GroupNode`, `DirEntity`)

```ts
{
  ...БазовіПоля,
  children: TAnyNode[]; // Масив дочірніх вузлів
}
```

## 4. Додаткове поле сутності (`FileEntity`, `DirEntity`)

```ts
{
  ...БазовіПоля,
  entity: string; // Назва сутності з секції entities
}
```

Зведена таблиця за типами:

| Тип вузла    | Поля                           |
| ------------ | ------------------------------ |
| `FileNode`   | базові + файлові               |
| `DirNode`    | базові + `children`            |
| `FileEntity` | базові + файлові + `entity`    |
| `DirEntity`  | базові + `children` + `entity` |
| `LayerNode`  | базові + `children`            |
| `GroupNode`  | базові + `children`            |
